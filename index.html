Firmware updates over Ethernet

I configured a silicon Ethernet switch and built a TCP/IP command interface on LwIP. It runs in two places, under FreeRTOS in the application and bare-metal in the bootloader, with the same interface in both so boards can be updated in the field.

A CAN diagnostics tool for technicians in the field

Michigan Tech, EE3174 final project, Fall 2025

Smart Lighting System

A motion-controlled light switch on an STM32 Nucleo, with a resistive touchscreen as the interface. It drives a relay in three modes: ON and OFF behave like a normal switch, and AUTO turns the light on when a mmWave radar sensor detects motion.

The touchscreen has three screens: one to pick the mode, one for settings (motion sensitivity, inactivity timeout, screen brightness), and one for diagnostics (time since last motion, activation count, errors, and a system reset).

I wrote the drivers for the display, touch controller, and radar sensor, plus recovery routines that reset the I2C and SPI buses to a known state.

C, STM32 (NUCLEO-L152RE), SPI, I2C, UART

Personal project, August 2025

Two-player scoreboard

A standalone scoreboard for two players, built on an Arduino Mega 2560. Each player has one button and a pair of 7-segment displays. Tap to add a point, and the board plays up to 21 and requires a win by 2. When someone wins, their score flashes.

Holding either button for three seconds resets the whole board through the Mega's reset pin. The display code is table-driven and written for common-anode segments, with out-of-range values blanking the digit.

C++, Arduino Mega 2560, 7-segment displays, GPIO
